# VIFIT — Centro de Entrenamiento Personal Premium

Web oficial de VIFIT, centro de entrenamiento personal premium ubicado en Bañeres de Mariola, Alicante.

**Producción:** https://vifit.vicentesanzcoach.com  
**Hosting:** Netlify  
**Stack:** HTML5 + CSS3 + JavaScript (web estática)

## Desarrollo local

```bash
npx browser-sync start --server --files "*.html, *.css, *.js, img/**/*" --port 5500
```

Luego abrir http://localhost:5500

## Estructura

- `index.html` — Landing principal (single page)
- `styles.css` — Estilos globales
- `script.js` — Interacciones JS
- `img/` — Fotos y logos
- `img/marcas/` — Logos de marcas de equipamiento (Maniak, GymLeco, Etenon, Rogue)
